# Contributing

Use Node 24.22.2 and `npm ci --ignore-scripts`. Run `npm run typecheck`, `npm run lint`, `npm run format:check`, `npm run build` and the applicable browser suites before proposing changes. Browser tests expect the local FULL_NODE service on 127.0.0.1:3006; Pages tests use 3010.

Preserve the Sazzad MIT notice, dependency licenses and asset provenance. Public screenshots must depict the actual product. Do not commit private PDFs, employment proof originals, passwords, access configurations, recordings containing private resumes, browser profiles or `.env.local`.

For animation changes describe lifecycle ownership, reduced-motion behavior and return/focus restoration. For responsive changes supply screenshots and native-zoom measurements; a viewport emulation alone is not native browser zoom. No contributor may claim that GitHub Pages implements server-side authentication.
