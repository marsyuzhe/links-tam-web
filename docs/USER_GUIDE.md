# 访客与本人使用说明

首页可滚动阅读简介、作品和技能。项目档案可搜索与按阶段筛选，详情可切换真实截图与艺术封面；图片支持放大、方向键、ESC 与关闭后恢复焦点。

Craft 入口在二级导航。文字区域可移动鼠标或点“揭示/重组/复原”；触摸与键盘使用按钮。工作台图片可展开，浏览器返回也能收回。单键可点击或按 Enter，选择不同材质、显示结构。底部选择技术或项目节点，查看对应的真实档案。

首页四枚记忆键帽默认不列公司，点击进入专属经历。返回后恢复原键帽和阅读位置。手机只需单次点击；滚动拖动不会误打开。

Resume 需本人提供的查看密码，公开说明不提供口令。解锁后可阅读网页经历，查看或下载正式原 PDF。打印正式文件请在 PDF 预览器打印；“锁定简历”清除会话。英文界面也使用同一份中文原文件。

社区与职业作品分开，有返回个人官网入口。规划中/尚未配置表示未验证服务，在线人数“—”不是零人。已确认在线才显示已验证的人数。状态异常、过期时不要据此判断可加入。公告、版本、模组和加入信息以实际发布内容为准；当前没有开放地址、公开公告或获准玩家截图。

手机上导航会换行，PDF 使用逐页可选择文字的预览。系统启用“减少动态效果”会使用简化动画和 2.5D 键帽，所有主要操作仍可用。
